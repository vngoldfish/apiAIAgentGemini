API Endpoints & Usage Examples

POST /v1/chat/completions

OpenAI-compatible text generation endpoint. Supports streaming and conversation history.

curl http://HOST_IP:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gemini",
    "messages": [
      {"role": "user", "content": "Tell me a joke!"}
    ],
    "stream": false
  }'
POST /v1/images/generations

OpenAI-compatible image generation using Google's Imagen model. Downloads images locally.

curl http://HOST_IP:8000/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A futuristic city in violet and cyan colors"
  }'

Giới Thiệu Gemini API Studio

Gemini API Studio là giải pháp tối ưu giúp bạn xây dựng, quản lý và phân phối API từ các tài khoản Google Gemini một cách ổn định, tự động xoay vòng tài khoản (load balance) và dự phòng lỗi (failover) thời gian thực. Hệ thống cung cấp API chuẩn định dạng OpenAI giúp dễ dàng tích hợp vào bất kỳ ứng dụng AI nào hiện có.

Xoay Vòng Tài Khoản Tự Động
Tự động điều phối các request qua danh sách tài khoản Gemini đang hoạt động, giúp tăng giới hạn băng thông (rate limit) tối đa.
Cơ Chế Dự Phòng (Failover)
Khi một tài khoản gặp lỗi cookie hoặc bị khóa, hệ thống tự động phát hiện và chuyển tiếp request tới tài khoản khỏe mạnh khác ngay lập tức.
Quản Lý AI Agents Cực Mạng
Thiết lập các Agent riêng biệt với System Prompt độc lập, tuỳ chỉnh nhiệt độ (Temperature), model và thậm chí liên kết API Key giới hạn.
Theo Dõi Traffic Thời Gian Thực
Giám sát toàn bộ lưu lượng request, tốc độ phản hồi (latency), số lượng token tiêu thụ và IP client gọi API trực quan sinh động.
Hướng Dẫn Sử Dụng Từng Bước
1
Lấy Cookie Tài Khoản Gemini
Truy cập vào trang web Google Gemini và đăng nhập. Nhấn F12 (hoặc click chuột phải chọn Inspect), mở tab Application (Chrome/Edge) hoặc Storage (Firefox), tìm mục Cookies, chọn trang gemini.google.com và copy giá trị của cookie tên là __Secure-1PSID.
2
Thêm Tài Khoản Vào Providers Pool
Vào tab Providers trong Dashboard này, click chọn Add Account. Nhập tên gợi nhớ (ví dụ: Tài khoản 1) và dán giá trị cookie __Secure-1PSID vừa copy vào. Click Add Account để lưu. Hệ thống sẽ tự động xác minh trạng thái hoạt động của tài khoản đó.
3
Tạo AI Agent (Nếu Cần)
Vào tab AI Agents, click Create Agent. Điền tên Agent, System Prompt (ví dụ: "Bạn là chuyên gia dịch thuật tiếng Anh..."), chọn Base Model thích hợp (Gemini 1.5 Flash, Gemini 1.5 Pro, v.v.), điều chỉnh Temperature và click Save Agent.
4
Tạo API Key
Vào tab API Keys, click Generate Key. Nhập tên nhãn gợi nhớ và chọn Scope (quyền hạn):
  • General Access: Quyền gọi API chung, có thể chỉ định model khi gọi request.
  • Agent-specific: Chỉ có quyền gọi đến một Agent cụ thể đã tạo ở Bước 3. Tiện lợi cho việc phân quyền hoặc bán API cho bên thứ ba.
5
Tích Hợp API Vào Ứng Dụng
Sử dụng API Key vừa tạo để gọi đến endpoint OpenAI-compatible của server này. Xem hướng dẫn code mẫu ngay phần bên dưới.
Tích Hợp API (Code Samples)

Server hỗ trợ endpoint chuẩn OpenAI Chat Completions tại địa chỉ: http://<IP-CỦA-SERVER>:8000/v1/chat/completions. Bạn có thể sử dụng các thư viện chuẩn của OpenAI hoặc gửi trực tiếp qua HTTP Client.

Chuẩn OpenAI API 
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gemini-1.5-flash",
    "messages": [
      {"role": "user", "content": "Xin chào, giới thiệu bản thân đi!"}
    ],
    "temperature": 0.7
  }'
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="http://localhost:8000/v1"
)

response = client.chat.completions.create(
    model="gemini-1.5-flash",
    messages=[
        {"role": "user", "content": "Chào bạn!"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
Các Câu Hỏi Thường Gặp (FAQs)
1. Cookie __Secure-1PSID của tài khoản Gemini có thời hạn bao lâu?
Cookie của Google thường có thời hạn khá dài (lên tới vài tháng) nếu bạn không thực hiện đăng xuất thủ công tài khoản đó trên trình duyệt hoặc đổi mật khẩu. Nếu trạng thái tài khoản chuyển sang Expired, bạn chỉ cần lấy lại cookie mới và click Cập nhật ở bảng Providers là xong.
2. Tài khoản mặc định (Fallback Default) hoạt động thế nào?
Hệ thống tích hợp sẵn một tài khoản mặc định để phòng trường hợp bạn chưa cấu hình tài khoản nào mà vẫn muốn kiểm tra API hoạt động. Tuy nhiên, tài khoản mặc định này có giới hạn request cực thấp và dùng chung cho toàn hệ thống. Bạn nên tự thêm các tài khoản Gemini cá nhân để có hiệu năng tốt nhất.
3. Tại sao request của tôi bị báo lỗi 429 (Too Many Requests)?
Do Google Gemini Web App áp dụng Rate Limit (giới hạn tần suất) trên mỗi tài khoản. Để khắc phục, hãy thêm nhiều tài khoản hơn vào Providers Pool. Thuật toán cân bằng tải của server sẽ tự động xoay vòng tài khoản, giúp giảm đáng kể tỷ lệ gặp lỗi 429 của bạn.
4. Điểm khác biệt giữa API Key loại General và Agent-specific?
API Key loại General cho phép client gọi đến bất kỳ mô hình nào được hệ thống hỗ trợ. Còn API Key loại Agent-specific bắt buộc client chỉ được tương tác với Agent cụ thể đã được lập trình sẵn Prompt. Khi sử dụng Agent-specific Key, client không cần truyền tham số model khi gọi API vì server sẽ tự động định tuyến tới Agent tương ứng.
5. Làm cách nào để đổi mật khẩu quản trị Dashboard?
Trong tab Overview, bên dưới phần thông tin Trạng thái hệ thống, bạn sẽ thấy bảng Cấu hình & Mật khẩu. Nhập mật khẩu hiện tại (mặc định là 123456) và nhập mật khẩu mới của bạn để đổi. Việc đổi mật khẩu sẽ làm hết hiệu lực tất cả các phiên đăng nhập Dashboard hiện tại trên các thiết bị khác.
